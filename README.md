Jogo do número secreto

Jogo em que o jogador tenta descobrir um número de 1 a 10, com dicas de maior ou menor e contador de tentativas. O layout parte de um curso de front-end.

Para rodar, abra o index.html no navegador. A lógica está em app.js.

Feito com HTML, CSS e JavaScript. As imagens da pasta img/ vêm do material do curso.
